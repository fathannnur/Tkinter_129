Program dimulai dengan mengimpor library Tkinter yang digunakan untuk membuat tampilan GUI. Selanjutnya, program membuat jendela utama dengan judul Aplikasi Prediksi Prodi Pilihan, ukuran 650 × 500 piksel, dan latar belakang berwarna putih. Setelah itu, program menampilkan label judul sebagai identitas aplikasi. Program kemudian membuat Frame sebagai wadah untuk mengatur komponen input nilai mata pelajaran. Dengan menggunakan perulangan for dan range(10), program membuat 10 label nama mata pelajaran beserta 10 kolom Entry yang dapat diisi oleh pengguna. Setiap kolom input disimpan ke dalam list nilai menggunakan append(). Setelah seluruh kolom tersedia, program membuat tombol Hasil Prediksi yang terhubung dengan fungsi hasil_prediksi(). Ketika tombol diklik, fungsi tersebut dijalankan dan mengubah teks pada label hasil menggunakan config() menjadi Hasil Prediksi: Teknologi Informasi dengan warna tulisan hijau. Hasil prediksi selalu menampilkan Teknologi Informasi karena program belum menggunakan nilai yang dimasukkan untuk melakukan perhitungan. Terakhir, root.mainloop() dijalankan agar jendela aplikasi tetap terbuka dan dapat menerima interaksi dari pengguna.
